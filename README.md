## ÁREAS DE ESPECIALIZACIÓN

* **Arquitecturas Backend & Sistemas Distribuidos:** Diseño e implementación de servicios desacoplados, APIs RESTful de alto rendimiento, microservicios y monolitos modulares estructurados para alta disponibilidad y fácil mantenimiento.
* **Inteligencia Artificial Aplicada:** Integración de modelos LLM (Google Gemini API, Ollama, LangChain) en flujos de trabajo empresariales, agentes autónomos y sistemas RAG (Retrieval-Augmented Generation).
* **Automatización de Procesos & Bots:** Orquestación de pipelines complejos con n8n, integración de webhooks y desarrollo de motores de mensajería automatizada con la API de WhatsApp.
* **Ingeniería Frontend de Alta Performance:** Construcción de aplicaciones web interactivas con Next.js y React, priorizando renderizado estático/híbrido, animaciones fluidas con aceleración por hardware (GSAP, Lenis) y máximos estándares de Core Web Vitals.
* **Infraestructura & Seguridad:** Contenedorización con Docker, configuración de proxies inversos NGINX, hardening en servidores Linux y automatización de despliegues continuos mediante CI/CD.
